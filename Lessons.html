I Learned about the all IT112 Lessons!

MODULE 1: Appreciation of History of Computing

TOPIC 1

History of computing

In this topic, I learned how computing started, why people created tools to help with calculations, the important people who contributed to the development of computing, and how these early inventions developed into the modern technology we use today.

TOPIC 2

Social history of computing

In this lesson, I learned how computing has changed different parts of society, including education, communication, healthcare, business, entertainment, and government. I also learned about the challenges that come with technology, such as privacy issues, cybersecurity threats, job loss, unequal access, misinformation, and technology addiction.

TOPIC 3

Development of user interaction

In this lesson, I learned how people have interacted with computers over time, from punch cards and command-line interfaces to graphical interfaces, touchscreens, voice commands, and modern AI. I also learned how these changes have made computers easier to use, more efficient, and more accessible to people.

Module 2: Concept of Computer System

TOPIC 1

Introduction of computing

In this topic, I learned what computers are, how they work, and how they are used in our daily lives. I also learned computers basic job, input, processing, output, storage and the cycles.

TOPIC 2

Components of computer system

In this topic, I learned about the different components of a computer system and how they work together to process information. I also learned how each component has its own function and how they work together to help the computer perform tasks efficiently.

TOPIC 3

Number Systems

This presentation introduces Decimal, Binary, Octal, and Hexadecimal number systems and how computers use binary to represent and process digital data. It also covers number system conversions, binary addition, and the basics of IP addressing.

Module 3: Internet and Cyber Security

TOPIC 1

Introduction to computer networks

This lesson introduces computer networks and explains how devices connect and communicate. It covers network types, network topologies, networking hardware, and important components such as MAC addresses, IP addresses, and network protocols, The classifications of networks, including PAN, LAN, MAN, and WAN

TOPIC 2

Introduction to internet and World Wide Web

This lesson introduces the Internet and the World Wide Web and explains how they connect people and devices around the world. It covers how data travels through an ISP to servers, important web concepts like URLs and DNS, the difference between HTTP and HTTPS, and how the web has developed into dynamic websites and cloud-based applications.

TOPIC 3A

Introduction to HTML

In this lesson, I learned the basic concepts of HTML and how it is used to create and organize the content of a webpage. I learned about tags, elements, attributes, and different HTML elements like headings, paragraphs, links, images, and lists. I also learned how CSS is used to add style and design to webpages. Overall, I learned how HTML and CSS work together to create structured, organized, and attractive websites.

TOPIC 3B

Introduction to CSS

In this lesson, I learned how CSS is used to improve the appearance and layout of webpages. I became familiar with CSS syntax, selectors, properties, and values, as well as the different methods of applying CSS to HTML. I also learned how CSS can make webpages more organized, appealing, and user-friendly.

TOPIC 4

Type of Cyber threats

In this lesson, I learned about different types of cyber threats, including malware, phishing, social engineering, ransomware, and DDoS attacks. I also learned how to identify possible signs of these threats and how to take proper precautions to keep my information, devices, and online accounts safe.

TOPIC 5

Categories of cyber security

In this lesson, I learned about the main types of cybersecurity and how each one helps protect digital systems. I learned about Network Security, Information Security, Application Security, Endpoint Security, Cloud Security, Identity and Access Management, and Operational Security. I also learned about Defense in Depth, which uses different layers of security to provide better protection for systems, devices, networks, and important data.
